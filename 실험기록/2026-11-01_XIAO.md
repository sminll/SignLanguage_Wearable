- 측정 날짜: 2026-11-01
- 분석 및 기록 날짜: 2026-11-02 (한국 시간)
- 보드: XIAO nRF52840 Sense
- 참가자: subject1, 왼손
- 목적: ‘갑자기’, ‘머리’, ‘아프다’ 세 동작을 구분할 수 있는지 초기 확인
- 범위: 개별 동작 분류. 동작 순서를 인식해 ‘편두통’으로 조합하는 기능은 평가하지 않음.

## 분석 설정

```powershell
python train_sign_knn.py --date 2026-11-01 --board XIAO
```

- 입력: `data/sensor_dataset_v2.csv`
- 장치 선택 근거: `data/session_devices.csv`
- 특징: FSR 6개 + 가속도 3축 + 자이로 3축 각각의 평균·표준편차·최솟값·최댓값, 총 48개
- 전처리: 학습 데이터에서 중앙값 결측 보완 및 StandardScaler 학습
- 분류: KNN, k=3
- 분할: 회차 단위, 동작별 비율을 유지한 75% 학습 / 25% 평가, random_state=42
- 실행 시 기준 Git 커밋: `e6175c9`. 날짜·보드 선택 기능은 당시 로컬 미커밋 변경을 사용함.

## 해석 및 한계

이번 한 사람의 같은 수집 세션 안에서는 세 동작이 대체로 구분됐습니다.
평가 데이터가 동작별 5회뿐이라 오답 1개에 전체 정확도가 약 6.7%p 변합니다.
다른 사람, 장갑 재착용, 다른 날의 성능이나 실시간 인식 성능은 아직 확인하지 않았습니다.

‘머리’는 검지를 펴고 손을 들어 올리는 동작이라 FSR 반응이 작을 수 있으며,
오늘 데이터에는 IMU 변화가 있었습니다. 단, FSR+IMU를 함께 사용한 결과이므로
어떤 센서가 정확도에 얼마나 기여했는지는 확인하지 않았습니다.
평균 등 요약 특징은 움직임의 시간 순서를 직접 표현하지 않습니다.
