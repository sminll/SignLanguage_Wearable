# Subject 식별 기준

2026-11-05 사용자 확인: **subject 뒤 숫자가 같으면 같은 사람**이다.

- 예: `subject8` = `subject-8`, `subject1` = `subject-1`.
- 숫자형 ID만 정규화한다. 비숫자 임의 ID는 별도 확인이 필요하다.
- 원본 CSV의 subject_id는 변경하지 않는다. 분석에 `person=subjectN`을 추가한다.
- 날짜·측정 세션·착용 조건은 사람 번호와 별개로 유지한다.
- 사람을 평가용으로 분리할 때는 해당 번호의 초기·재측정·여러 날짜 데이터를 전부 학습에서 제외한다.
- 과거 삭제 데이터는 번호가 같다는 이유로 복원하지 않는다. 현재 존재하는 허용된 데이터에만 적용한다.
- 초기/위치 미통일 데이터의 포함 여부는 파일/세션 단위로 구분한다. 같은 사람의 재측정을 초기 데이터로 자동 분류하지 않는다.

실제 이번 정규화 매핑과 데이터 분포는 `data/knn_results/2026-11-05_app_loso_all_people/subject_id_mapping.csv` 및 `cohort_inventory.csv`에 기록했다.
