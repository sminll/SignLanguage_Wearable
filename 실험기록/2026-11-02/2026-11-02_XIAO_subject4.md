## 평가 후 새 통합 모델

- subject1의 동작 60회 + subject4의 동작 60회 = 총 120회
- 동작별 40회, 참가자별 각 동작 20회
- 기존 파이프라인을 복제한 새 객체로 결측 보완·스케일링·KNN을 처음부터 학습
- k=3, 휴식 클래스는 포함하지 않음
- 원본 모델과 다른 경로에 저장했으며 현재 서버·MATLAB에 자동 배포하지 않음
- **새 통합 모델의 독립적인 평가 정확도는 아직 없음**

subject4 데이터는 위 외부 평가를 완료한 뒤 통합 모델의 학습에 사용했으므로,
이제 통합 모델의 독립 시험 데이터로 재사용할 수 없음.
새 참가자나 별도 새 세션 데이터를 받으면 통합 모델을 고정해 다음 평가를 진행.
