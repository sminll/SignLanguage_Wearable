## 3. 삼키다의 작은 왼손 움직임도 두 사람에게 공통

회차별 가속도 3축 표준편차를 평균한 값은 subject-1 약 0.0056, subject-2 약 0.0062다. 왼손 자이로의 같은 지표는 약 0.82/0.72로 오른손 약 20.78/18.43보다 작다. **오른손만 움직이는 수어라면 정상적인 차이일 수 있다.** 동작 유형 확인 없이 왼손 기록을 불량으로 제외하지 않는다.

다음은 전체 샘플 가중 평균이며, 앞선 건강 분석의 회차 동일 가중 평균과 집계 방식이 다르다. 단위는 FSR 원시 저장값이다.

## 공통 제한 및 처리 방향

- 두 앱 ID 모두 동일 `session_id`를 사용한다. 참가자·회차까지 포함해 구분해야 하며 앱 세션만으로 평가 데이터를 나누면 안 된다. 앱 subject-2를 과거 MATLAB subject2와 임의 매핑하지 않는다.
- `calibration_version=UNREGISTERED`, `calibration_verified=false`가 공통이며, 수어 유형과 공통 측정 시계 의미도 아직 미확인이다. UTC `time`이 있으므로 시간이 아예 없는 것은 아니며 앱 구현을 확인해야 정밀 양손 정렬 가능 여부를 판단할 수 있다.
- **누락 때문에 즉시 제외할 회차는 없고 120개 모두 보존한다.** 오른손 FSR5와 왼손 개별 FSR 직접 누름 반응, 각 수어 사용 손, 동일 장갑 사용 여부·재착용 방향을 확인한다. 현재는 자동 학습하지 않는다.
- 확인 후 같은 수어라는 라벨을 유지하면서 사람별·착용 조건 차이를 분석한다. 추후 학습 시 사람을 분리한 양방향 평가(subject-1 학습 → subject-2 평가, 반대 방향)를 실시할 수 있다. 단 2명뿐인 점과 튜닝에 평가 데이터를 반복 사용하지 않는 점을 명시해야 한다.
