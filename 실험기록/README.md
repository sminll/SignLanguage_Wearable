## 기록 방법

날짜 폴더는 측정 날짜 기준입니다. 분석 날짜는 문서 안에 따로 적습니다. 새 기록은 [양식](기록양식.md)을 복사하고 현재 상태를 맨 위에 표시합니다.

- 보존: 원본·결과가 남아 있다는 뜻이며 자동 배포나 품질 보증을 뜻하지 않습니다.
- 학습 제외: 원본은 남기되 학습에 사용하지 않습니다. 삭제와 구분합니다.
- 삭제 이력: 사용자 요청으로 실제 원본이나 파생 모델을 삭제한 과거 처리 기록입니다.

모델의 정확도는 어떤 학습 데이터와 평가 데이터로 얻었는지 함께 읽어야 합니다. 같은 사람·세션·회차가 학습과 평가에 섞이지 않도록 합니다. 문서와 학습 제외 목록은 실행 때 자동으로 모든 학습 도구에 적용되는 것이 아니므로 실행 전 확인합니다.
