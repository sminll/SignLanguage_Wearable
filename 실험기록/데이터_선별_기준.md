# 측정 데이터 선별 기준

**현재 상태(2026-11-03): 앱 subject-1·2의 세 수어 120회차는 사용자 요청으로 학습 제외했습니다. 원본은 보존하고 오늘 생성한 모델은 사용 중단했습니다. 재포함은 별도 사용자 요청 후 진행합니다. 제외 목록은 data/training_exclusions.json이며 [모델 현황](모델_현황.md)을 참고합니다.**

2026-11-03 사용자와 합의한 운영 기준. 이후 앱·MATLAB 수집 데이터 검토에 적용한다.

- 원본은 보존하고 파일 전체보다 동작 회차 단위로 검사한다. 삭제는 별도 사용자 요청이 있을 때 수행한다.
- 측정자, 수어명, 손, 세션·회차 정보를 확인한다. 필수 정보가 없으면 확인 전까지 학습을 보류한다.
- 중복 샘플은 학습에 한 번만 사용한다. 심한 시간 공백, 짧거나 중단된 기록, 결측·비정상 센서값은 정도와 근거를 기록해 확인 또는 제외한다.
- 센서가 계속 고정되거나 최대값에 반복적으로 붙으면 상태를 확인한다. 자동으로 하드웨어 고장이라고 단정하지 않는다.
- 양손 학습은 같은 세션·회차의 양손이 모두 필요하다. 공통 시간 정보가 없으면 정밀 정렬이 검증되지 않았음을 표시한다. 시간을 임의 복원하거나 누락 손을 0으로 채우지 않는다.
- 잘못된 수어명·동작 실패가 확인되면 라벨 수정 또는 해당 회차 제외를 검토한다. 보정·연결 테스트 자료는 수어 학습 자료와 구분한다.
- FSR이 낮거나 기존 모델의 정답률이 낮다는 이유만으로 제외하지 않는다. 개인·자세·착용·동작 차이와 센서 문제를 구분한다.
- 판정은 **학습 후보 / 확인 필요 / 학습 제외**로 구분한다. 기본 검사 통과가 실제 동작의 정답을 보장하지는 않는다.
- 별도 사용 회차 목록에 파일·세션·회차·판정·이유를 남긴다. 원본을 자동 삭제하거나 새 데이터를 자동으로 기존 모델에 반영하지 않는다.
- 학습 후 학습에 포함하지 않은 사람·세션으로 평가한다. 같은 회차의 샘플이나 양손을 학습/평가에 나누어 넣지 않는다. 평가에 필요한 데이터가 부족하면 한계를 명시한다.
- GitHub 원본 수집은 `training-data`에서 검토하고 `main`에는 검증된 필요한 변경만 반영한다. 브랜치 전체를 자동 병합하지 않는다.

## 건강 양손 데이터에 적용한 해석

`건강`과 `건강 (앉아서)`는 같은 수어의 서로 다른 측정 조건으로 보관한다. 앉아서 측정한 세션의 FSR·IMU 분포 차이는 확인 사항이며 불량 확정 사유가 아니다. 사용자는 자세 차이를 주요 원인으로 추정했으나 원인 확정으로 기록하지 않는다.

## 다음 수집: 삼키다 / 상처 / 교통사고

- 2026-11-03 사용자 전달에 따른 예정 수어명은 `삼키다`, `상처`, `교통사고`이다. 아직 수신·검사 완료로 간주하지 않는다.
- 수어명은 동일한 표기로 저장하고 앉음 등 자세는 별도 조건으로 기록한다. 한 손/양손 여부는 실제 동작을 확인하고 기록한다.
- 기존 MATLAB Subject 번호 표는 [적용 안내](../legacy/docs/업데이트_적용방법.md#subject-번호)에 있다. 앱이 발급한 `subject-...` ID를 기존 `subjectN`과 임의로 동일시하지 않는다. 같은 사람인지 확인해 별도 매핑이 있어야 사람별 평가가 가능하다.
- 보정 기록은 실제 수어와 분리한다. 한 세션을 먼저 확인한 뒤 반복 측정을 늘리며, 공통 시간·동작 회차·양손 손 구분이 수집되는지 검사한다.
