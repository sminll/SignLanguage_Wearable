XIAO 기반 양손 센서를 이용한 6종 수어 KNN 분류 평가

2026년 11월 13~15일 수집된 참가자 9명의 실제 측정 데이터를 사용하여 괜찮다·아니다·무엇·마시다·화장실·싫다의 6개 수어를 분류하였다. 약 5초 동안 측정한 하나의 동작 회차를 하나의 평가 단위로 정의하고, 양손의 센서값을 각각 평균·표준편차·최솟값·최댓값으로 요약하였다. 총 1,060회 중 오른손 기록이 없는 16회를 양손 평가에서 제외하여 1,044회를 분석하였다. 제외한 원본 데이터는 삭제하지 않았다.

참가자 한 명의 모든 데이터를 평가용으로 분리하고 나머지 8명만으로 학습하는 과정을 9명에게 반복하였다. 센서 입력(IMU·FSR·전체)과 KNN 설정은 각 평가의 학습 참가자 안에서만 추가로 사람을 나누어 선택하였고, 표준화도 해당 학습 데이터에서만 계산하였다. 따라서 평가 참가자는 학습과 설정 선택 모두에서 제외되었다.

실제 평가 결과 1,044회 중 332회를 올바르게 분류하여 전체 정확도 31.80%를 얻었다. 참가자별 정확도의 동일 가중 평균은 32.05%이며 Macro F1은 0.307이다. 수어별 정답률은 괜찮다 10.92%, 아니다 90.00%, 무엇 14.04%, 마시다 46.29%, 화장실 12.21%, 싫다 14.53%이다.

혼동행렬은 세로축이 실제 수어, 가로축이 예측 수어이다. 각 칸은 예측 횟수와 해당 실제 수어 안에서의 비율을 표시하며, 대각선은 정답이다. 전체 정확도는 참가자별 백분율의 단순 평균이 아니라 전체 평가 회차의 정답 횟수를 합산하여 계산하였다.

이 결과는 수집된 9명의 데이터를 이용한 참가자 단위 중첩 교차검증 결과이다. 앞으로 새로 참가할 사람에 대한 전향적 외부 평가나 실시간 연속 수어·문장 인식 성능을 의미하지 않는다. 기존 세 수어 실험과는 수어 종류·참가자·평가 절차가 달라 정확도를 직접적인 향상 수치로 비교하지 않는다.
