# 559회차 통합 데이터의 고정 설정 LOSO

분석: 2026-11-08. 사용자 요청으로 통합 후보의 현재 설정(양손 IMU, 표준화, KNN k=3·맨해튼 거리)을 고정하고 전체 데이터의 사람별 교차검증을 계산했다. 원본 모델은 변경하지 않았다.

## 공유용 요약

초기 위치 미통일 120회차를 제외한 세 수어 데이터는 10명·559회차다. 현재 후보는 이를 모두 학습했다. 학습 전에 신규 4명을 따로 평가한 결과는 61.67%, 전체 자료에서 한 사람씩 빼는 내부 교차검증은 73.88%다. 둘은 평가 조건이 달라 직접적인 상승 폭으로 해석하지 않는다. 이미 학습한 데이터의 재예측 99.28%는 실제 새 사람 성능으로 공유하지 않는다. 다음 신규 참가자로 현재 후보를 평가한다.

subject5의 다른 수어 기록도 GitHub에 보존돼 있다. 이번에는 삼키다·상처·교통사고만 선택했기 때문에 subject5의 교통사고 20회만 포함했다. 다른 수어 기록을 누락·삭제한 것이 아니다.

## 점수의 구분

| 평가 방식 | 정답 | 해석 |
| --- | ---: | --- |
| 10명 전체에서 한 사람씩 빼고 재학습·평가(LOSO) | **413/559, 73.88%** | 현재 설정의 내부 교차검증 추정치 |
| 위 예측 중 세 수어가 있는 9명만 집계 | 413/539, 76.62% | 단일 수어 subject5의 평가를 뺀 집계; 학습에서 뺐다는 뜻 아님 |
| 저장된 통합 모델에 이미 학습한 559회차를 다시 입력 | 555/559, 99.28% | 훈련 데이터 재예측 점수, 일반화 정확도가 아님 |
| 통합 모델 자체의 새 미학습 참가자 평가 | 미실시 | 이후 새 참가자 필요 |

**73.88%는 하나의 통합 모델을 새 사람에게 적용한 독립 점수가 아니라, 사람을 바꾸며 임시로 학습한 10개 모델의 예측을 합친 점수다.** 설정을 일부 참가자 자료로 먼저 선택한 뒤 계산했으므로 낙관적일 수 있는 사후 내부 평가다. 이전 신규 4명 외부 평가 61.67%와 학습량·평가 대상이 달라 직접적인 개선 폭으로 비교하지 않는다.
