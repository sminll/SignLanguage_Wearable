## 학습 모델 및 다음 사용

교차검증 예측·모델·평가 결과를 모두 저장한 뒤, 두 개의 전체 학습 후보를 별도로 만들었다.

- `all_people_candidate_model.joblib`: 초기 포함 439회차·7명, 비교용.
- `without_initial_candidate_model.joblib`: 초기 제외 319회차·6명, 다음 새 참가자 평가에 우선 검토할 후보.
- 위 교차검증 수치는 사람을 뺀 여러 fold 모델의 성능이다. **전체 학습 후보 자체의 독립 정확도가 아니다.** 새로운 참가자의 데이터를 먼저 평가해야 한다.
- 두 후보 모두 자동 배포하지 않았다. 기존 8+10 및 다른 모델·원본은 유지했다.
- 반복적으로 같은 데이터를 분석한 상태라 이번 결과는 탐색 검증이다. 이후 이 결과로 특징을 고르거나 튜닝하면 최종 확인용 참가자를 따로 남긴다.
- 실제 착용 조건이 통일됐는지, 특히 왼손 FSR과 개별 채널 직접 누름 반응은 계속 확인해야 한다. 이번 비교가 기존 센서 주의사항을 해소하지는 않는다.

## 재현·산출물

```text
python -B tools/evaluate_app_loso.py --quality-dir data/knn_results/2026-11-05_new_sessions_quality --initial-quality-dir data/knn_results/2026-11-03_app_quality_compare --out data/knn_results/새_폴더명
```

출력: `data/knn_results/2026-11-05_app_loso_all_people/`.

- `subject_id_mapping.csv`, `cohort_inventory.csv`: 원래 ID·사람 번호·초기/후속 구분.
- `fold_summary.csv`, `all_predictions.csv`: 전체/초기 제외 참가자별 성능과 예측.
- `matched_later_trial_comparison.csv`: 같은 후속 평가 파일에 대한 초기 포함 효과.
- `all_sessions/subjectN/`, `without_initial/subjectN/`: 각각 학습 회차 목록·예측·혼동행렬·평가 JSON·fold 모델.
- `manifest.json`, 후보 2개와 각각의 manifest: 설정·범위·한계.
- 입력 blob 해시, 동일인 전체 세션 분리, 같은 319개 평가 파일 일치, 학습 전용 표준화, 저장 모델 재로딩 및 학습 샘플 수를 검증했다.
