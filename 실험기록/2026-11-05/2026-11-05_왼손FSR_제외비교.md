# 2026-11-05 왼손 FSR 제외 효과 비교

## 결론

**왼손 FSR만 제외하면 200/319(62.70%)에서 202/319(63.32%)로, 정답 2회·약 0.63%p 증가했다. 이번 비교에서는 변화가 작아 왼손 FSR만이 저정확도의 주원인이라고 단정할 수 없다.**

이번 작업은 0인 데이터 행이나 참가자 전체를 삭제한 것이 아니다. 같은 회차를 유지한 채 **모델 입력 채널만** 바꿨다. 원본·기존 후보 모델을 변경하지 않았고 새로운 전체 학습 모델로 교체하지 않았다.

## 고정 조건

- 초기 120회차를 제외한 319회차·6명, Git 기준 `9ca2b603362f8ced0cb12e3d179ce4214da8bdad`.
- 사용자 확인대로 숫자 동일인으로 묶은 LOSO. 각 사람의 모든 날짜·세션은 같은 그룹이다.
- 모든 구성에서 같은 319개 평가 파일·동일 학습 참가자 분할을 사용했다. 같은 회차의 손/행을 다른 집합으로 나누지 않았다.
- 중앙값 대체·StandardScaler·KNN k=3 고정. 전처리는 각 fold의 학습 데이터에서만 계산했다.
- 전체 센서 조건의 예측이 이전 초기 제외 LOSO 예측과 **파일별로 완전히 일치**하는지 확인했다.
- 실제 수어의 사용 손이나 0의 원인을 판정한 실험은 아니다. 압박·센서·보정·착용 방향에 관한 기존 확인 사항은 유지한다.

## 해석과 다음 단계

- 왼손 저압/0만 제거하면 큰 폭으로 개선될 것이라는 가설은 이번 결과에서는 지지되지 않는다. 단, 작은 효과나 하드웨어 정상/비정상을 통계적으로 확정한 것은 아니다.
- 오른손 FSR·사람별 압박 차이도 검토할 가치가 있다. IMU 전용은 비교 후보로 유지하되 교통사고 손실을 확인해야 한다.
- 센서 개별 직접 누름 시험은 여전히 필요하다. 이번 성능 비교는 센서 고장 검사가 아니다.
- 이미 반복 평가한 참가자로 하는 사후 진단이다. 이 결과를 보고 입력을 선택하면 이후 새로운 참가자로 최종 확인해야 한다. 기존 초기 제외 전체 센서 모델을 자동 교체하지 않았다.
