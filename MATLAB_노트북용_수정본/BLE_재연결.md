# USB / 보조배터리 전원 변경 후 BLE 모니터 재연결

보드 전원을 끊으면 기존 MATLAB `b`, `c` 연결도 끊어집니다. 전원을 다시 켠 뒤 기존 연결을 정리하고 알림을 다시 구독해야 합니다. 이전 그래프나 버퍼의 패킷만으로 현재 연결 상태를 판단하지 마세요.

1. XIAO에 USB 또는 보조배터리 전원을 연결합니다.
2. MATLAB 현재 폴더를 이 폴더로 변경하거나, 이 폴더의 실제 경로를 `addpath`로 등록합니다.
3. `blelist`에서 대상 보드 주소를 확인합니다. 같은 이름의 보드가 여러 개면 실제 사용할 보드 주소를 선택합니다.
4. 명령 창에서 실행합니다.

```matlab
xiao_ble_address = "YOUR_BLE_ADDRESS"; % blelist에서 확인한 주소
xiao_ble_reconnect
```

스크립트는 기존 1개 보드 테스트 창을 닫고 작업 공간의 `b`, `c`를 새 연결로 교체합니다. 알림 구독 후 `xiao_ble_single_ui_test(c)`를 실행합니다. 전원이 바뀔 때마다 같은 스크립트를 다시 실행하세요. 자동 재연결 기능은 아닙니다.

수신 횟수가 계속 증가하고, 보드를 움직이거나 FSR을 누를 때 그래프가 바뀌는지 확인합니다. 이 모니터는 왼손 영역에 보드 하나를 표시하므로 오른손 영역은 비어 있습니다. FSR이 계속 0이면 실제 압력 반응과 배선·전원을 별도로 확인하세요.

실물 확인: MATLAB R2026b, XIAO nRF52840 Sense에서 컴퓨터 USB 연결을 해제하고 보조배터리로 전원을 바꾼 뒤 수동 재연결 절차로 FSR 변화와 IMU 그래프 갱신을 확인했습니다.
