# 2026-11-01 실물 테스트 완료 기록

## 테스트한 구성
- MATLAB R2026b, XIAO nRF52840 Sense, BLE 알림 수신.
- 컴퓨터 USB 및 보조배터리 전원으로 구동. 전원 변경 후 BLE 재연결.
- 단일 보드 모니터에서 측정자·수어명·손 선택, 수집 및 CSV 저장, 버튼을 통한 서버 전송.
- 서버 전송 주소: `http://100.92.15.45:5000/sensor`.
- `/health`에서 HTTP 200 및 `status: ok`, `dataset: sensor_dataset_v2.csv` 응답 확인.

사용자는 최종 수정본으로 테스트를 완료했고 이상이 없었다고 보고했습니다. 이 기록은 사용자의 실물 테스트 완료 보고이며, 서버 CSV를 별도로 내려받아 행 단위 대조한 기록은 아닙니다.

## 포함된 수정
- 5초 측정 + 3초 휴식 × 20회 수집, 일시중지 및 계속 수집.
- 실제 선택한 왼손/오른손과 측정자·세션·수어명을 함께 기록.
- CSV 저장 확인 후 백그라운드 HTTP 전송. 첫 미확인 응답에서 중단하고 자동 재전송 방지.
- CSV 예외 처리와 임시 파일 정리 수정.
- 전원 변경 후 기존 BLE 객체를 정리하는 재연결 스크립트.
- MATLAB 현재 폴더에 구버전 함수가 있어도 모니터 폴더의 함수를 사용하도록 고정. 입력 인수 개수 충돌 해결.

## 실행 위치
MATLAB 현재 폴더를 이 폴더(`MATLAB_노트북용_수정본`)로 설정한 뒤 실행하는 것을 권장합니다. 이전 Downloads 폴더의 동명 함수를 사용하지 않도록 주의하세요.

```matlab
xiao_ble_address = "YOUR_BLE_ADDRESS"; % blelist에서 확인
xiao_ble_reconnect
```

모니터에서 측정자·수어명·손을 선택하고 **20회 수집 시작**, 완료 후 **Python 서버로 전송**을 누릅니다. 시작만으로 자동 전송되지 않습니다.

## 자동 검증
기존 payload/수집 주기·CSV·로컬 HTTP·UI 검증 24개와 BLE 디코더 검사가 통과했습니다. 이후 구버전 현재 폴더 충돌을 재현한 회귀 테스트를 추가하고 단일 모니터 테스트 2개를 다시 실행해 통과했습니다. 로컬 HTTP 검증은 임시 수신기를 사용했고 가짜 센서값을 실제 서버로 보내지 않았습니다.

측정 CSV, 개인별 원본 센서 데이터, 임시 로그는 이번 코드 PR에 추가하지 않습니다.
