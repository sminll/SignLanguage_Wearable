# 구버전 코드 및 문서

2026-11-02에 현재 실행 파일과 과거 자료를 구분하기 위해 정리했습니다.
현재 수집은 최상위 `receive_sensor.py`, 재전송은 `resend_sensor_v2.py`,
학습은 `train_sign_knn.py`를 사용합니다. MATLAB 수집 화면은 기존 위치에 있습니다.

| 폴더 | 보관 내용 |
|---|---|
| `python/` | 이전 수신 서버, 이전 CSV 재전송, 과거 Subject 라벨링 도구 |
| `simulation/` | 가상 데이터 생성·검사·그래프 예제와 `data/sensor_test.csv` |
| `docs/` | 이전 시리얼 실행 순서, 업데이트 및 폴더 통합 안내 |

`python/` 안의 도구는 이동 전과 같이 프로젝트 최상위 `data/`를 참조하도록
경로만 수정했습니다. 이전 API·IP를 사용하는 도구이므로 현재 수신 서버 대신 실행하지 마세요.
가상 데이터 예제는 `simulation/data/`를 사용해 실제 측정 데이터와 분리합니다.
