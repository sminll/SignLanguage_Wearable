`http://127.0.0.1:5000`에서 정상 대기하면 성공입니다. **MATLAB을 실행하는 동안 서버 터미널을 끄지 마세요.** 같은 노트북에서 측정하므로 Tailscale이 필요 없습니다.

## 3. MATLAB으로 측정하기

1. 기존 MATLAB 그래프 창이 열려 있다면 닫습니다.
2. MATLAB에서 `MATLAB_노트북용_수정본` 폴더를 Current Folder로 설정합니다.
3. Command Window에 입력합니다.

```matlab
clear fsr_live_monitor fsr_http_collection make_sensor_payload write_sensor_csv post_sensor_batch
serialportlist("available")
```

ESP32 포트가 `COM3`이면 다음과 같이 실행합니다 (다른 번호가 나오면 바꿉니다).

```matlab
fsr_live_monitor("COM3")
```

4. **Subject(이름 포함)**를 선택한 뒤 동작명, 손을 설정합니다.
5. **20회 수집 시작**을 누르면 확인창이 나옵니다. **이름·수어·손을 보고 확인**하세요.
6. 5초 측정 + 3초 휴식 × 20회를 수행합니다.
7. 측정 후 **전송**을 누르면 최종 확인창이 나옵니다. Python이 새 `sensor_dataset_v2.csv`에 수신·저장합니다.
8. 새 MATLAB 원본 CSV는 `MATLAB_노트북용_수정본/sensor_data`에 **19열**(`subject_id`, `session_id` 포함)로 따로 저장됩니다.

## 4. 입력을 잘못한 경우

**측정 시작 전:** Subject/수어/손을 다시 선택하세요. 확인창에서 취소할 수 있습니다.

**측정 후, 전송 전:** `중지` → Subject 또는 수어명 변경 → **`정보 수정`** → 확인 → CSV가 정정됐는지 확인 → **`전송`**. 손 선택은 수집 시작 뒤 변경할 수 없으므로 손을 잘못 골랐다면 측정 데이터를 보류하고 다시 측정하세요.

**Python으로 전송한 뒤:** 데이터 서버와 MATLAB 측정을 멈춘 다음 아래 명령어로 세션을 확인합니다.

```powershell
python correct_session.py list
```

수정할 **정확한 session_id**를 찾아 아래처럼 실행합니다 (예시는 실제 측정이 아닙니다).

```powershell
python correct_session.py edit s20261031_123000_123456789 subject3 아프다
```

- 해당 세션의 Subject/수어 이름만 정정합니다.
- 실행 전 **자동으로** `data/backups/`에 통합 CSV를 백업합니다.
- MATLAB 원본 측정 파일은 그대로이며, **AI 학습에는 새 통합 CSV만** 사용합니다.

- 예전 **17열 MATLAB CSV**는 이 전송 프로그램을 지원하지 않습니다. 이전 데이터는 이미 6,777행에 포함되어 있습니다.

## 7. MATLAB 렉 관련

- 실시간 **그래프 표시 빈도만 약 4회/초로 낮추고**, CSV는 묶어서 기록하게 했습니다.
- ESP32 원시 센서의 실제 샘플링 설정과 5초/3초 구간을 나누는 규칙은 바꾸지 않았습니다.
- **실제 노트북에서 문제가 개선되는지는 미검증입니다.** 기존 20회 전체를 수집하기 전에 1~2회 측정하고 중지하여 CSV, 화면의 시간 표시, 전송을 확인하세요.
- 화면이 여러 회차씩 점프하는 현상이 반복되면 수집을 멈추고 새 데이터는 평가용에서 보류하세요.
