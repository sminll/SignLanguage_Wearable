# 수민님 노트북용 MATLAB 센서 수집 안내

이 폴더는 하드웨어팀이 공유한 MATLAB 코드 9개와 원래 실행방법.md를 포함합니다. 원본과 다른 파일은 아래 두 개입니다.
- fsr_http_collection.m: POST 주소를 127.0.0.1:5000/sensor로 변경. 같은 노트북에서 실행 중인 Python 서버에 전송합니다.
- post_sensor_batch.m: 원본 17개 센서 필드를 현재 receive_sensor.py가 저장하는 source/hand/trial_id/label/fsr1..6/ax..gz 필드로 변환합니다.

## 준비
1. MATLAB 데스크톱 버전 설치 및 로그인(원래 코드 문서는 R2025b를 기준으로 합니다).
2. 이 폴더의 `.m` 파일을 한 폴더에 같이 둡니다.
3. USB로 ESP32 및 센서를 노트북에 연결합니다. ESP32에는 115200 baud에서 `ms, FSR 6개, IMU 7개`를 출력하는 Arduino 펌웨어가 미리 업로드되어 있어야 합니다. 해당 Arduino .ino 파일은 이번 업로드에 포함되지 않았습니다.
4. Arduino IDE 시리얼 모니터·시리얼 플로터를 닫습니다.

## 시작
1. 노트북에서 `SignLanguage_Wearable` 프로젝트의 터미널을 열고 `python receive_sensor.py` 실행. `127.0.0.1:5000`에서 접속 가능해야 합니다.
2. MATLAB 앱을 열고 Current Folder를 이 `.m` 파일들이 있는 폴더로 맞춥니다.
3. MATLAB Command Window에서 `serialportlist("available")` 실행해 연결된 COM 포트를 확인합니다.
4. 예를 들어 장치가 COM5라면 MATLAB Command Window에서 `fsr_live_monitor("COM5")` 실행합니다. 실제 포트명으로 바꾸세요.
5. 실시간 그래프가 갱신되는지 확인합니다.
6. 위쪽 `동작명` 입력 및 왼손/오른손 선택 후 `20회 수집 시작` 클릭. 5초 동작 + 3초 휴식 x 20회입니다. **휴식 구간은 CSV에 저장되지 않습니다.**
7. 수집이 완료되면 파일은 이 폴더 아래 `sensor_data`에 자동 저장됩니다. 수집 완료만으로 POST되지는 않습니다. 데이터를 확인한 다음 `전송` 버튼을 누릅니다.
8. Python 쪽 `data/received_sensor.csv`에서 `source=REAL`, `label=동작명`, `hand=left/right`와 실제 센서값 저장 여부를 확인합니다.

## 오류 예방
- `fsr_live_monitor`만 실행하면 Windows COM 포트 자동 선택이 안 될 수 있으니 `fsr_live_monitor("COM5")`처럼 포트를 명시하세요.
- 실시간 데이터가 들어오지 않으면 Arduino .ino가 올바르게 업로드되었는지 확인하세요.
- 전송이 실패했을 경우 중복 저장 위험이 있어 무조건 다시 전송하지 말고 수신 CSV부터 확인하세요.
- 이미 저장된 같은 동작의 CSV를 다시 전송하면 Python 서버가 중복 저장합니다.
- 테스트는 짧게 `20회 수집 시작` 후 중지하고 전송할 수 있습니다. 다만 `REAL`로 저장되므로 테스트용 레이블(예: `연결시험`)로 분리하고 학습에서 제외하세요.
- 시리얼 모니터와 MATLAB은 같은 포트를 동시에 점유하지 않도록 하세요.
- GitHub에서 이전에 받았던 `received_sensor.csv`에 누적할 예정이면 `git pull` 후 수집, 수집 종료 후 commit/push를 순서대로 하세요.

## 자체 테스트(장치와 서버 없이)
MATLAB에서 다음을 실행하면 CSV/수집 로직을 검사하도록 작성된 테스트를 실행합니다.
`runtests({'test_sensor_http.m','test_sensor_collection_review.m','test_sensor_csv.m'})`
업로드된 파일을 이 환경에서 MATLAB으로 실행 검증한 것은 아니므로, 오류 발생 시 오류 메시지를 확인해야 합니다.
