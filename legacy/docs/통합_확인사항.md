# 수어 웨어러블 프로젝트 통합 안내

## 통합 결과

- 이 폴더는 기존 `SignLanguage_Wearable-1`을 기준으로 병합한 **새 복사본**입니다. 업로드하신 ZIP 2개를 읽기만 했으며 원본은 변경하지 않았습니다.
- 기존 Python 파일, Git 저장소 정보(`.git`), `data/received_sensor.csv` 및 `data/received_sensor_with_subject.csv` 원본 바이트를 **수정하지 않고 그대로 보관**했습니다.
- 기존 `SignLanguage_Wearable`의 `MATLAB_노트북용_수정본/` 폴더와 그 안의 실측 원본 CSV 6개를 추가했습니다.
- 동일한 경로지만 내용이 달랐던 `main.py`, `check_data.py`, `data/sensor_test.csv`는 **GitHub 프로젝트(-1)의 파일을 우선 유지**하고, 이전 폴더의 파일은 `archive_original_folder/`에 별도 보관했습니다. 따라서 어느 쪽도 지워지지 않았습니다.
- 두 ZIP에서 `.env` 파일은 발견되지 않았습니다.

## 확인된 센서 데이터 현황

- `data/received_sensor.csv`: **6,777행**(실제 센서 6,776행 + TEST 1행)
- `data/received_sensor_with_subject.csv`: **6,777행**(별도 `subject_id` 추가)
- `MATLAB_노트북용_수정본/sensor_data/` 원본 6개: **각 968행, 총 5,808행**
- 10월 30일 원본 MATLAB 데이터 5,808행과 Python 수신 CSV의 같은 날짜 5,808행은 동작, 회차, time_ms, FSR 6개 및 IMU 6개 기준으로 **모두 일치**합니다. 따라서 이 5,808행을 또 합쳐서 중복 추가하지 않았습니다.
- 10월 29일 `가위` 968행은 Python 수신 CSV에 보존되어 있습니다. 이번 업로드에는 해당 MATLAB 원본 CSV가 포함되지 않았습니다.

### Subject 번호 확인이 필요한 부분

- `subject1`: 10월 29일 `가위` **968행**
- `subject2`: 10월 30일 `아프다`, `어렵다`, `못하다` **각 968행, 총 2,904행**
- `subject3`: 10월 30일 `아프다`, `어렵다`, `안된다` **각 968행, 총 2,904행**
- TEST 데이터 1행은 subject_id가 비어 있습니다.

**주의:** 사용자가 이전에 말씀하신 '10월 29일 subject1 / 10월 30일 subject2' 기록과 달리, 업로드된 CSV에는 10월 30일 데이터 일부가 `subject3`으로 기록되어 있습니다. 실제 측정자가 맞는지 확인 전에는 Subject 번호를 바꾸지 마세요. 이 통합본에서는 원본 CSV를 수정하지 않았습니다.

## 안전한 사용 순서 (Windows)

1. **기존 `SignLanguage_Wearable` 및 `SignLanguage_Wearable-1` 폴더는 그대로 두세요.** ZIP 압축도 보관하세요.
2. `SignLanguage_Wearable_통합본.zip` 압축을 해제하면 `SignLanguage_Wearable_MERGED` 폴더가 생깁니다.
3. VS Code에서 **File → Open Folder → `SignLanguage_Wearable_MERGED`**를 선택하세요.
4. VS Code PowerShell 터미널에서 `git status`를 실행해 GitHub 연결을 확인하세요. `.git`은 기존 `-1` 폴더에서 그대로 복사해 왔습니다.
5. 새 폴더에서 `python receive_sensor.py`로 Python 서버를 실행하고, MATLAB에서 **현재 폴더를 새 폴더 안의 `MATLAB_노트북용_수정본`으로 변경**한 뒤 센서를 연결해 실행하세요. 실행 전 기존에 열려 있는 서버나 MATLAB 그래프 창은 정상 종료해 두세요.
6. **CSV 행 수와 새 데이터 수신을 확인하기 전에는 기존 폴더를 삭제하지 마세요.** 확인이 끝나더라도 별도 백업을 보관하는 편이 안전합니다.

**중요:** Python 수신 서버는 실행 중인 Python 스크립트 파일의 위치를 기준으로 `data/received_sensor.csv`에 저장합니다. 예전 `-1` 폴더의 서버를 켜 둔 채 새 MATLAB만 실행하면 데이터가 예전 폴더로 저장될 수 있으니, 사용할 프로젝트를 하나로 통일하세요.

## 코드 수정 범위

- 이번 작업은 **폴더·파일 통합만 수행**했습니다.
- Python 수신 코드에 Subject 1~10 직접 저장 기능을 추가하지 않았습니다.
- MATLAB의 측정 화면 Subject 드롭다운, CSV/전송 Subject 연동, 수집 렉 최적화는 아직 적용하지 않았습니다.
- 이 기능들은 기존 데이터를 안전하게 보존한 상태에서 별도 변경과 검증이 필요합니다.
