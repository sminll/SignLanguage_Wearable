# 구현 및 검증 순서

1. 단일 BLE 모니터에 기존 payload/CSV/전송 함수를 사용하는 수집 상태와 버튼 동작을 추가한다.
2. 단일·양손·시리얼 수집기의 전송 주소를 지정 Tailscale /sensor 주소로 통일한다.
3. 수집 데이터는 타이머로 CSV에 저장하고, 명시적 전송 전 저장 성공을 확인한다.
4. HTTP는 backgroundPool에서 처리하며 첫 미확인 응답에서 중단하고 자동 재시도하지 않는다.
5. 기존 payload/CSV/디코더 테스트와 로컬 HTTP 성공·부분 실패 검증을 실행한다.
6. 실제 서버 접근 가능 여부를 확인하고 변경 브랜치 및 PR을 생성한다.
