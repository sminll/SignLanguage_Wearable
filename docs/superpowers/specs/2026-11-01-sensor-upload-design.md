# 단일 보드 센서 수집 및 서버 전송

## 목적
USB/보조배터리로 구동하는 XIAO 1개의 BLE 센서값을 MATLAB에서 수집한 뒤 사용자가 버튼을 눌러 지정 서버에 전송한다.

## 방식
선택한 방식은 수집 후 버튼 전송이다. 실시간 전송은 미완성 측정값까지 서버에 기록하므로 사용하지 않는다. 기존 make_sensor_payload / write_sensor_csv / post_sensor_batch 함수를 재사용한다.

## 변경
- 단일 보드 모니터에 수어명, 측정자, 왼손/오른손 선택과 수집 시작·일시중지·전송 버튼을 제공한다.
- 기존 수집 방식과 동일하게 5초 측정 + 3초 휴식, 20회 수집한다. 일시중지 시 측정 시간을 보존한다.
- 전송 전에 수집 데이터를 CSV에 저장한다. 빈 수집, 수집 중, 전송 중에는 전송 버튼을 비활성화한다.
- 전송 완료 건수와 미확인 건수 및 오류를 표시한다. 응답이 유실될 경우 중복 전송 위험이 있어 자동 재시도하지 않으며 CSV는 보존한다.
- 단일 보드 모니터 및 저장소의 기존 수집·양손 모니터의 전송 주소를 http://100.92.15.45:5000/sensor 로 통일한다.
- 기존 재연결 스크립트는 같은 모니터를 계속 실행한다. 펌웨어와 서버 API 형식은 변경하지 않는다.

## 검증 및 한계
기존 MATLAB payload/CSV/수집 주기 테스트, HTTP 성공·부분 실패 처리 검증과 모니터 화면 검증을 수행한다. 실제 서버 연결이 불가능하면 로컬 HTTP 수신기로 검증하고 PR에 원격 검증 미완료를 명시한다. 허위 측정 데이터는 실제 서버에 보내지 않는다.
