## 포함 내용

- 보드·날짜별 CSV와 통합 실측 CSV
- 세션별 ESP32/XIAO 매핑 (참가자 이름·로그인 정보 없음)
- 11월 1일 XIAO KNN의 특징 데이터, 모델, 평가 보고서와 혼동행렬
- 독립 실행용 학습 코드와 라이브러리 버전 목록
- 파일별 SHA-256 manifest 및 사용 안내
